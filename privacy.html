Privacy Policy

CV Bank · last updated 26 September 2026

CV Bank is a personal script run by a single person on their own computer. It has no server, no database and no other users.

What Google data it accesses

The app requests one Google scope: drive.readonly — read-only access to files in the signed-in user's Google Drive. It uses this only to read a spreadsheet of received job applications and to download the CV files attached to those applications. It never creates, edits or deletes anything in Google Drive.

Where the data goes

Downloaded files are written to folders on the user's own computer. Nothing is uploaded anywhere, nothing is sent to any server operated by this app, and nothing is shared with any third party. The app has no analytics and no tracking.

Authentication

Sign-in uses Google OAuth. The resulting token is stored in a single file (token.json) on the user's computer and is used only to call the Google Drive API.

Retention and deletion

Downloaded files stay on the user's computer until the user deletes them. Access can be revoked at any time at myaccount.google.com/permissions; deleting token.json removes the stored credential from the computer.

Limited Use

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
