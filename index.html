CV Bank

A private tool for filing job applicants' CVs.

CV Bank is a small personal script used by one recruiter to keep candidate CVs organised. It reads the CV files that applicants submit through an online application form and files them into folders on the recruiter's own computer, named by department and position.

Who uses it

One person — the Google account owner who installed it. It is not a public service, has no user accounts, and is not offered to anyone else.

Google data

The tool requests read-only access to Google Drive so it can download the CV files. It never writes to, changes or deletes anything in Drive. See the privacy policy.
